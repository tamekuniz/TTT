# 要件: 録音中マイクアイコン UI の改善

## 背景

ズンジー: 「アプリ起動時 水色のマイクアイコン → クリックすると停止アイコンに変化 → 音声入力すると停止アイコンが震える。なにこれ。」「正直うんこ」「入力中なのに停止アイコンなの？」「赤はやめなよ。停止の色なんだから」「せめて青にしな」

要は:
- 録音中の状態を表すのに「停止アイコン (stop.fill)」を出すのは UI として混乱を招く（「停止」は操作を表すアイコンであって状態ではない）
- 録音中の色が赤なのは、赤が「停止/警告」の色なので、状態として「録音中」を意味するには不適切
- 録音中も「マイクアイコンのまま」「色は青系」にするのが望ましい

## ゴール

録音中のマイクボタンの見た目を以下に変更する:

1. **アイコン**: 録音中も `mic.fill` のまま（`stop.fill` への切り替えを撤廃）
2. **色**: 録音中の `.red` を青系に変更
   - 起点: RGB(0.05, 0.35, 0.80)（待機=準備完了の RGB(0.10, 0.47, 0.95) より濃いめの青）
   - 微調整は Step 8 の実機確認で
3. **パルスアニメーション**: 既存の scale 1.08 / opacity 0.85 / repeatForever を維持
4. **状態区別**:
   - 待機（モデル未ロード）: 既存の水色 RGB(0.45, 0.83, 0.98)
   - 待機（準備完了）: 既存の鮮やかな青 RGB(0.10, 0.47, 0.95)
   - 録音中: 新しい濃い青 RGB(0.05, 0.35, 0.80) + パルス

## 非ゴール

- アイコンの種類変更（mic.fill 以外への切替）
- 録音停止操作の方法変更（再クリックで停止する仕様は維持）
- 録音中の音量レベル可視化（波形・レベルメーター追加）
- 触覚/視覚フィードバック（録音開始/停止時のハプティクス）の変更
- 「準備完了」と「録音中」の青の差を厳密に定量化（実機調整に委ねる）

## 影響範囲（Step 3 で精査）

- `Sources/TypeToTalk/App/TypeToTalkApp.swift`
  - `micButtonColor` private var（L113-123）: 録音中の `.red` 分岐
  - `Image(systemName: ... ? "stop.fill" : "mic.fill")`（L60 周辺）: アイコン分岐

## 受け入れ条件

1. アプリ起動時: 水色のマイクアイコン（既存挙動）
2. クリック後（録音中）: アイコンは **mic.fill のまま**、色は **濃い青**、パルスアニメーション継続
3. もう一度クリック（停止）: 元の色（待機=準備完了の鮮やかな青）に戻る
4. 録音停止 → 文字起こし中（isProcessing）: 既存の ProgressView 表示は変更なし
