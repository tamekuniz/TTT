# requirements: なるべくそのままモード追加

## Goal

整形 AI のモードに「なるべくそのまま」（promptMode 値 `"asIs"`）を追加する。選択時は WhisperKit が出力した文字起こしテキストに対して **フィラー削除と明らかな言い間違い修正のみ** を行い、それ以外（語順・文体・言い回し・冗長性・改行）は触らずに通す。

「なるべくそのまま」が必要な場面: 発言の語彙・口調・順序そのものを残したい用途（メモ起こし・引用・発言記録・人格再現等）。整形 AI の「整える」処理がニュアンスを毀損する場面の救済。

## Constraints

1. **既存3プロバイダー全対応**: Groq / OpenAI / Bonsai のすべてで動く。systemPrompt の差し替えだけで対応する（プロバイダー側コードや API 呼び出しロジックには手を入れない方針）。
2. **言語両対応**: `formatterLanguage = "ja"` / `"en"` の両方で動く。それぞれの言語で「フィラー」「言い間違い」の例示が言語ネイティブに伝わるプロンプトを用意する。
3. **既存ユーザーの custom systemPrompt を破壊しない**: 既存の `promptMode = "custom"` ユーザーが編集してきた `systemPrompt` テキストには触らない。新モードはあくまで `promptMode` の選択肢追加であって、既存値の上書きや初期化はしない。
4. **新規 promptMode 値**: `promptMode` に新規値 `"asIs"` を 1 つ足す設計。既存値（`"custom"` 等）と並列で切り替え可能にする。
5. **文体設定無視**: `"asIs"` 選択時は `formatterStyle`（`desuMasu` / `daDearu` / `auto`）は無視し、文体変換を行わない（語尾の置き換えもしない）。WhisperKit が出力した語尾をそのまま通す。

## Acceptance criteria

1. 設定画面の整形プリセット選択 UI（promptMode を切り替える既存 UI）で「なるべくそのまま」が選択肢として表示される。
2. `promptMode = "asIs"` を選択した状態で「えーっと、明日は雨が降る、あっ、晴れだった」を入力 → 「明日は晴れる。」相当の出力（フィラー「えーっと」削除 + 言い間違い「雨が降る、あっ、晴れだった」を「晴れる」に修正、文体・順序は維持）。
3. ja / en 両言語で「フィラー削除と言い間違い修正のみ通る／それ以外は触らない」ことを実機（macOS）で確認できる。
